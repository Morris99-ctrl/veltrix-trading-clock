VELTRIX TRADING CLOCK v10.3 — MARKET SESSION INTELLIGENCE VALIDATION

Implemented
- Added selectable profiles: Current Configuration, Forex Standard, Equities Cash, Extended Monitoring and Custom.
- Added a custom market schedule editor for local open/close times and Monday-Sunday active weekdays.
- Selected profile, baseline schedule and custom profile overrides are persisted in config.json.
- Added weekly scheduled-hours and active-day reports calculated in each market's local timezone/week.
- Added reconstructed 7/30/90-day scheduled-overlap reports with total hours, average daily hours, busiest UTC day and pair breakdown.
- Added tests for preset/custom profile validation, schedule metadata/timezone preservation, weekly scheduled hours, historical overlap totals/pairs, input validation and config persistence.
- Updated README, desktop installation guide, quick-start, changelog and Windows version metadata.

Important interpretation
- Weekly hours are schedule calculations for each market's local Monday-Sunday week.
- Historical overlap analytics reconstruct prior schedules using the currently selected profile and IANA timezone rules. They are not observed market history. Unknown public holidays, emergency closures, special sessions and broker-specific hours are not included.

Required automated checks
1. Run: python -m compileall -q .
2. Run: python -m unittest discover -s tests -v
3. Build the Windows desktop package with GitHub Actions.
4. Verify the v10.3 Windows executable exists and the artifact upload succeeds.

Required manual Windows checks

2. Edit custom open/close times and weekdays; save, restart, and confirm the Custom profile and baseline schedule persist.
3. Verify weekly scheduled hours around Sydney/London daylight-saving transitions.
4. Verify 7/30/90-day overlap totals and pair breakdowns against known test schedules.
5. Switch all six themes and confirm analytics labels, profile controls, custom editor and timeline remain legible.

No claim of actual historical exchange-open observations, live market status or trading profitability is made.
